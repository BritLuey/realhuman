# Getting help

## 1. Check the docs

Most questions are answered in:

- [Troubleshooting](docs/operations/troubleshooting.md): common problems and fixes
- [Configuration reference](docs/reference/configuration.md): every option
- [Glossary](docs/glossary.md): unfamiliar terms

## 2. Search existing issues

Someone may have hit the same thing:
[search issues](https://github.com/your-org/realhuman/issues?q=is%3Aissue).

## 3. Ask

| You have… | Go to |
|---|---|
| A question about using realHuman | [GitHub Discussions → Q&A](https://github.com/your-org/realhuman/discussions) |
| A bug (something doesn't work as documented) | [Bug report](https://github.com/your-org/realhuman/issues/new?template=bug_report.yml) |
| A bot that realHuman scores as human, or a person scored as a bot | [Detection report](https://github.com/your-org/realhuman/issues/new?template=detection_report.yml) |
| An idea for a feature | [Feature request](https://github.com/your-org/realhuman/issues/new?template=feature_request.yml) |
| A security vulnerability | **Privately**, following [SECURITY.md](SECURITY.md) |

When asking, please include your package versions, platform (Vercel / CloudFront / Node) and, if relevant,
a decision record with any `context` values removed.

## Response times

realHuman is maintained on a best-effort basis by its maintainers and community. There's no guaranteed
response time for questions. Security reports follow the timeline in [SECURITY.md](SECURITY.md).
