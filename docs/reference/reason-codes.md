# Reason codes

> [!NOTE]
> Defined as `REASONS` and `REASON_CODES` in `@realhuman/schema` and produced by `@realhuman/engine`. A test in
> the schema package fails if any code is missing from this page.

Every decision record has a `reasons` array explaining the score. Reason codes go to **your backend only**
and are never sent to the browser.

**Lean** shows which way a code pushes the score: towards **bot**, towards **human**, or **neutral**
(context only).

```ts
import { REASONS } from '@realhuman/schema';

REASONS.honeypot_filled; // { group: 'gate', lean: 'bot', description: 'A hidden honeypot form field was filled in.' }
```

## Gates

Gates are conclusive on their own. If any gate fires, analysis stops, the score is set near `0`, and
`engine` is `gate`.

| Code | Lean | Meaning |
|---|---|---|
| `honeypot_filled` | bot | A hidden honeypot form field was filled in. |
| `honeypot_trap_followed` | bot | An invisible trap link was followed. |
| `agent_canary_followed` | bot | Hidden instructions aimed at AI agents were acted on. |
| `nonce_invalid` | bot | The session nonce was missing, malformed or had a bad signature. |
| `nonce_expired` | bot | The session nonce was older than its allowed lifetime. |
| `nonce_replayed` | bot | The nonce was presented from a different TLS client or browser than it was issued to. |
| `too_fast` | bot | The client reported more elapsed time than had really passed since the nonce was issued, a sign of a fast-forwarded clock. |
| `ja4_non_browser` | bot | The TLS fingerprint belongs to a non-browser HTTP library while the user agent claims to be a browser. |
| `automation_markers` | bot | Globals or properties left behind by an automation framework were found. |
| `ua_bot` | bot | The user agent openly identifies itself as a bot, crawler or HTTP library. |

## Environment

| Code | Lean | Meaning |
|---|---|---|
| `webdriver` | bot | `navigator.webdriver` is true. |
| `headless_markers` | bot | Traits typical of a headless browser were found. |
| `software_renderer` | bot | Graphics are rendered in software, which is typical of servers and headless browsers. |
| `ua_client_hints_mismatch` | bot | The user-agent string disagrees with the browser's User-Agent Client Hints. |
| `worker_mismatch` | bot | Browser properties differ between the page and a Web Worker, a sign of spoofing. |
| `feature_mismatch` | bot | The browser lacks features its claimed version should have. |
| `native_tamper` | bot | Built-in browser functions have been overwritten. |
| `privacy_browser` | neutral | A privacy-hardened browser was detected. Consistency penalties are switched off for this session. |

## Network

| Code | Lean | Meaning |
|---|---|---|
| `ua_ja4_mismatch` | bot | The TLS fingerprint does not match the browser family in the user agent. |
| `sec_fetch_missing` | bot | Fetch metadata headers (`Sec-Fetch-*`) that this browser always sends were missing. |
| `timezone_mismatch` | bot | The browser's time zone differs from the time zone of its IP address. VPN users also trigger this, so it is weighted lightly. |
| `verified_agent_signature` | neutral | The request carried a valid Web Bot Auth signature from a declared agent. |

## Behaviour

| Code | Lean | Meaning |
|---|---|---|
| `synthetic_events` | bot | Input events were generated by script (`isTrusted` was false). |
| `pointer_linear` | bot | Pointer movement followed unnaturally straight lines at constant speed. |
| `pointer_teleport` | bot | Clicks happened with no pointer movement leading up to them. |
| `click_dead_center` | bot | Clicks landed exactly in the centre of their targets. |
| `keyboard_uniform` | bot | Key presses were evenly spaced, as a script would type. |
| `form_too_fast` | bot | A protected form was submitted faster than a person could fill it in. |
| `pointer_natural` | human | Pointer movement had natural curvature, speed changes and pauses. |
| `keyboard_natural` | human | Typing rhythm varied in the way human typing does. |
| `touch_natural` | human | Touch contact size, pressure and timing varied naturally. |
| `scroll_natural` | human | Scrolling showed natural acceleration and rhythm. |
| `no_interaction` | neutral | No interaction yet. This lowers confidence but does not lower the score on its own. |

## Engine

| Code | Lean | Meaning |
|---|---|---|
| `no_js` | neutral | The client never ran the browser SDK. Only network evidence was available. |
| `jev_decision` | neutral | The score was produced by the Jev engine. |
| `jev_unavailable` | neutral | The Jev engine timed out or returned an error, so the algorithmic engine scored this session. |

## How to read them

- A record can have **several** codes. They are listed roughly in order of influence.
- **Bot-leaning codes don't automatically mean "bot".** One weak signal, such as `timezone_mismatch` from a
  VPN user, is easily outweighed by strong human evidence. The score already accounts for that.
- New codes may be added in minor releases. Treat unknown codes as neutral.
