# Signals

> [!NOTE]
> Collected by `@realhuman/client`; the format is defined in `@realhuman/schema` (`SignalsSchema`).

This page lists everything the browser SDK collects, why it helps, and how privacy is protected.

## Privacy rules that apply to every signal

1. **Summaries only.** The SDK computes statistics such as averages, variation and counts in the browser.
   Raw events (coordinates, keys, timestamps) never leave the page.
2. **No content.** Key values, form contents, clipboard data and page text are never read.
3. **No stable identifiers.** No canvas, audio, font or hardware fingerprints are computed. Values that
   could single out a device are reduced to yes/no answers, for example "is graphics rendered in software?"
   rather than "which graphics card?".
4. **No storage.** Nothing is written to cookies, localStorage, sessionStorage or IndexedDB.

## Environment (`env`)

| Field | What it means | Why it helps | Privacy treatment |
|---|---|---|---|
| `webdriver` | `navigator.webdriver` is true | Set by standard browser automation | Boolean |
| `automationMarkers` | Frameworks whose leftovers were found (`playwright`, `puppeteer`, `selenium`, `webdriverio`, `phantomjs`, `nightmare`, `cdp`, `other`) | Near-certain evidence of automation | List of fixed labels |
| `headlessMarkers` | Headless traits (`ua_headless`, `zero_outer_size`, `missing_window_chrome`, `permissions_inconsistent`, `no_plugins`, `no_browser_ui`, `viewport_is_screen`) | Headless browsers differ from real ones in small ways. `no_browser_ui` means a desktop window with no tabs or address bar, and `viewport_is_screen` a page exactly the size of the screen, the default headless window (neither is checked in fullscreen or on mobile); `zero_outer_size` is weak evidence because embedded and in-app browsers report it too, and it's ignored on mobile. A `HeadlessChrome` user agent is decisive (`ua_bot`) | List of fixed labels |
| `softwareRenderer` | Graphics are drawn in software (e.g. SwiftShader, llvmpipe) | Typical of servers and headless browsers, but also remote desktops and VMs, so it's weak evidence | Boolean; the GPU name is never sent |
| `rendererPlatformMismatch` | The graphics stack belongs to a different operating system than the browser claims (Direct3D means Windows, Metal or Apple GPUs mean Apple, Mesa means Linux) | Bots on Linux servers often claim to be Windows or Mac, but can't easily change their graphics driver | Boolean; the GPU name is never sent. `null` when the graphics details can't be read |
| `uaClientHintsMismatch` | User-agent string disagrees with Client Hints | Spoofed user agents rarely fix both | Boolean |
| `workerMismatch` | Page and Web Worker report different browser details or graphics renderers | Spoofing scripts usually only patch the page, while a Worker sees the real values | Boolean |
| `featureMismatch` | Browser lacks features its claimed version has | Exposes old or fake browsers posing as new ones | Boolean |
| `nativeTamper` | Built-in getters on `navigator`, `screen` or `window` (sizes and position) have been overwritten, or wrapped in a Proxy (detected in Chromium browsers) | Stealth plugins patch browser internals. Graphics and canvas functions aren't checked, because session-replay tools such as rrweb, PostHog and Sentry wrap them legitimately; the Worker comparison covers graphics instead | Boolean |
| `privacyBrowser` | Privacy-hardened browser detected (`brave`, `firefox_rfp`, `tor`, `safari_atfp`, `other`) | Prevents false alarms: these browsers are inconsistent on purpose | Fixed label |
| `timezone` | IANA time zone, e.g. `Europe/London` | Compared with the IP's time zone to spot proxies | Same coarse value already exposed to every site |
| `maxTouchPoints` | Number of touch points supported | Consistency with the claimed device | Small integer |

## Pointer (`pointer`)

| Field | What it means | Why it helps |
|---|---|---|
| `events` | Number of pointer moves | Amount of evidence |
| `trustedRatio` | Share of events generated by real input (`isTrusted`) | Script-generated events are untrusted |
| `coalescedPerMove` | Average high-frequency samples per move event | Real hardware produces coalesced events; synthetic events usually don't |
| `speedMean`, `speedCv` | Average speed and how much it varies | People accelerate and decelerate; scripts often move at constant speed |
| `accelerationCv` | Variation in acceleration | Human movement is jerky in characteristic ways |
| `curvatureMean` | Average path curvature | People move in curves; scripts in straight lines |
| `straightRatio` | Share of perfectly straight segments | As above |
| `pauses` | Number of hesitations | People pause to read and think |
| `clicks` | Number of clicks | Amount of evidence |
| `teleportClicks` | Clicks with no movement before them | Scripts often click without moving |
| `centerClicks` | Clicks exactly in the centre of the target | Scripts aim for the centre; people don't |
| `pointerTypes` | Counts of mouse / pen / touch events | Consistency with the device |
| `pressureVariance` | Variation in pen/touch pressure (null if unsupported) | Real pressure varies |

No coordinates are ever sent. Positions are used only inside the browser to compute these statistics.

## Keyboard (`keyboard`)

| Field | What it means | Why it helps |
|---|---|---|
| `events` | Number of key presses | Amount of evidence |
| `trustedRatio` | Share of real (trusted) key events | Script-typed text is untrusted |
| `holdMeanMs`, `holdCv` | How long keys are held, and how much that varies | People hold keys for uneven lengths of time |
| `gapMeanMs`, `gapCv` | Time between key presses, and how much that varies | Scripts type with even gaps |
| `pastes` | Number of paste events | Context for the rhythm statistics |
| `keyClasses` | Counts of `character`, `editing` (Backspace/Delete), `navigation` (arrows, Tab), `modifier` keys | People correct mistakes; scripts rarely press Backspace |

**Which keys were pressed is never recorded**, only the class they fall into.

## Touch (`touch`)

| Field | What it means | Why it helps |
|---|---|---|
| `events` | Number of touch events | Amount of evidence |
| `trustedRatio` | Share of real touch events | Synthetic touches are untrusted |
| `radiusVariance` | Variation in finger contact size (null if unsupported) | Real fingers vary; emulated touches are uniform |
| `forceVariance` | Variation in touch pressure (null if unsupported) | As above |
| `multiTouch` | Number of multi-finger gestures | Pinch/zoom is hard to fake convincingly |
| `tapMeanMs` | Average tap duration | Emulated taps are often instantaneous |

## Scroll (`scroll`)

| Field | What it means | Why it helps |
|---|---|---|
| `events`, `wheelEvents` | Scroll and wheel event counts | Amount of evidence |
| `deltaModes` | Counts of pixel / line / page wheel deltas | Mouse wheels and trackpads behave differently; scripts often use neither pattern |
| `quantizedRatio` | Share of scrolls in identical fixed steps | Programmatic scrolling is evenly stepped |
| `cadenceCv` | Variation in scroll rhythm | People scroll in bursts |

## Timing (`timing`)

| Field | What it means | Why it helps |
|---|---|---|
| `firstInteractionMs` | Time from start to first interaction (null if none) | Instant interaction is suspicious, as is none at all |
| `rafJitterMs` | Variation in animation frame timing | Headless and virtualised browsers render at unusual rates |
| `eventLoopLagMs` | How busy the page's main thread is | Automation tooling can add characteristic lag |
| `clockDriftMs` | Difference between wall-clock and monotonic time | Bots that fast-forward clocks show drift |
| `visibilityChanges`, `focusChanges` | Tab switches and focus changes | Real people switch tabs |
| `domContentLoadedMs` | Page load time | Context for other timings |

## Honeypot (`honeypot`)

| Field | What it means |
|---|---|
| `fields` | Number of honeypot fields injected |
| `filled` | Number of honeypot fields that were filled in |
| `trapFollowed` | The invisible trap link was followed |
| `canaryFollowed` | AI-agent canary instructions were acted on |
| `fastSubmits` | Forms submitted faster than `minFillMs` |
| `syntheticClicks` | Clicks on elements no person can reach |

See [Honeypots](../guides/honeypots.md).

## Network evidence (read on the server, not collected by the SDK)

| Evidence | Source | Stored as |
|---|---|---|
| JA4 TLS fingerprint | CDN header | `server.ja4` (identical for every user of the same browser build, so it doesn't identify a person) |
| User agent | Request header | `server.uaFamily`, `server.uaMajor`, `server.platform` only |
| Client Hints | Request headers | `server.clientHintsPresent` + consistency checks |
| Fetch metadata | Request headers | `server.secFetchPresent` |
| IP time zone | CDN header | `server.timezoneMatch` only. The IP address itself is never read or stored. |
| Web Bot Auth signature | Request headers | `server.verifiedAgent` |
